# 微台 LightGBM 研究管線

初版規格固定於2026-11-15。2026-11-17新增[完整期貨日盤、夜盤與有限候選滾動研究](tmf-sessions.md)：最多1096天、純期貨8特徵、分類／淨收益模型、三段滾動驗證與保存門檻。以下舊12特徵／0.5門檻規格仍適用 `cash` 固定分類模式。訓練本身不自動啟動或替換交易規則；Paper可使用日／夜盤，Sandbox保留日盤，正式Live仍不支援。

- 從目前行情連線分批下載，每批最多31天；舊 `cash` 模式取TMF近月連續日盤及固定四檔股票（2330、2454、2317、2881），新完整日／夜盤僅取期貨。每根期貨保存官方實際合約月，不由查詢月 `1!` 推測。原始快照壓縮保存SQLite，內容雜湊定版；缺段、不交易平日、股票不同步與換月均顯示。
- 特徵只用當日日盤已收盤價格／量、ATR、開盤區間距離及四檔股票近5分報酬；不使用事後權重或盤後欄位，仍揭露固定現今股票選擇的偏誤。跨日重設，避免把未調整換月價差當成報酬。
- 樣本為09:20–13:10的5分開盤區間穿越事件，不將每分鐘視為獨立交易。標籤依下一根開盤＋不利滑價進場、V2固定距離／2R、最多20分鐘或13:20退出計算淨損益是否大於0。雙觸採停損，跳空採不利開盤；費率來源保留快照，稅額逐口每邊取整。
- 按完整交易日60%／20%／20%分訓練、驗證、封存測試，依實際標籤結束時間移除跨界樣本。驗證與測試不參與特徵選擇、調參或閾值搜尋。固定LightGBM binary、50輪、depth3、7葉、min_data_in_leaf15、learning_rate0.05、L2=1、seed42、最多2執行緒，分數閾值0.5；沒有參數搜尋。
- 標籤品質診斷最低20個訓練事件與兩種標籤，足夠才產生模型；不足則保存可讀原因。研究候選比較另要求至少60個完整日、60訓練／20驗證／20測試事件；此為第一版研究門檻，並非統計充分條件。
- 驗證與封存測試各自模擬完整事件序列：每方向最多一次、單口單部位、日損1000、風險預算包含費稅。不以分類準確率代替收益。候選須兩期一般及每邊額外2點壓力淨值皆正、一般情境優於相同事件V2基準且回撤不擴大；持續前測仍需另行驗證。
- 所有報告、分割、特徵、設定、套件版與模型hash保存本機；不提交行情或個人費率。固定規則下重訓新版本，重複相同輸入去重，保留前版。模型可匯出為LightGBM文字格式，不反序列化外來pickle。
- 來源是sandbox或合成資料、存在缺段／現今選股偏誤／未核對休市時，報告維持研究用途，不產生可自動送單的核准。訓練報告始終 `executionEnabled=false`，不自動啟動或授權正式交易；使用者可另外選入模擬前測。通過數值門檻也僅是研究候選。模型分數沒有校準為未來勝率。

## 操作與依賴

`pnpm start` 會安裝 Python `learning` extra。macOS 原生 LightGBM 另需先執行 `brew install libomp`；也可手動 `uv sync --directory server --extra test --extra fubon --extra learning`。只啟動 bridge 時，使用 `uv run --directory server --extra learning fubon-bridge`。

在「策略回測」面板的微台商品下，選擇歷史起訖日並分批下載，再選擇資料版本訓練；沿用上方單口成本設定。下載後可查看缺段／無資料平日／股票數量，訓練後查看日期切分、事件數、成本壓力與拒絕原因。選舊版本查看原設定；新費率不改寫舊報告。有原生模型的版本可匯出文字檔。

背景工作與自動交易共用 SQLite 原子 lease，工作中禁止啟動策略，有策略或曝險時禁止下載／訓練。每15秒續租；失去執行權、啟動失敗與關機都釋放自己的 lease。服務重啟不把舊工作當作自動恢復；已保存下載批次可重試續傳。

新增模型、特徵／標籤程式及正規化程式的 source hash 參與版本，避免修公式後命中舊快取。相關套件版本與完整參數保存於報告；原始行情／模型／費率都只存本機 SQLite，不提交 Git。
