# LightGBM 進場濾網接入

日期：2026-11-16。沿用本機 LightGBM 訓練管線，新增由使用者選定模型的 Paper／Sandbox 實驗流程；不啟動策略、不開放 Live、不宣告模型具有獲利優勢。

- ORB 決定方向，LightGBM 只以固定 0.5 門檻保留或跳過進場。訓練與即時推論共用同一個特徵函式，只讀決策當下已完成的期貨及四檔股票分鐘棒；缺漏、重複或非有限特徵不進場。
- 模型 ID、原生文字檔 SHA-256、特徵順序、規則版本及程式來源雜湊必須吻合。只載入本機訓練產物，不接收外部模型或 pickle。訓練資料日期必須早於交易日。
- 使用 V2 ATR 風控、單口、最多兩次意圖、日損預算 1000。停損下限、停利倍數、費稅及滑價必須與訓練報告一致。選取模型會顯示並套用這些設定，使用者啟動時由後端再次核對。
- 與訓練標籤一致，以訊號時間加 20 分鐘或 13:20 較早者請求退出。停損、停利、預算與退出監控不依賴模型推論；模型失效仍保留既有曝險的退出能力。
- 模型固定到本日計畫；有意圖後不能更換。每次判斷保存模型 ID／雜湊、特徵、分數、門檻與通過／拒絕原因；已保存意圖也保存模型與退出期限。
- 有原生模型的研究診斷版本可手動選入模擬前測，合成資料模型不允許送測試單。數值比較未通過時明示原因，不提升為正式採用資格。報告的 `executionEnabled=false` 仍表示訓練不會自動啟動或授權正式交易。
- 舊模型來源雜湊不符時要求用原資料重新訓練，不改寫舊報告。服務重啟後仍須手動恢復；缺模型／損壞模型拒絕新倉，不回退成無濾網交易。

驗證涵蓋真實 LightGBM fit／載入／推論、離線與即時特徵一致、未來資料排除、模型完整性、日期與成本不符、通過／拒絕訊號、模型失敗及重啟後的退出監控。模擬驗證與真實盤中前測分開報告。

## 本輪驗證

- 後端232個測試、前端5874個測試（另2個既有跳過）、`tsc -b` 與 Vite build 通過。
- 獨立 QA 修正兩個問題並複查通過：非整數R在ATR後保留原始倍數，避免先取整改變停利；歷次判斷原子保存至 `research_auto_model_decisions`，不隨 `lastSignal` 更新而消失。
- 推論例外與非有限分數的回歸同時核對停止新倉、當次模型特徵與失敗原因，以及重新讀取資料庫後的不可變判斷紀錄。
- 瀏覽器驗收沿用 `scripts/verify-auto-trading.mjs` 的臨時資料庫／虛擬Passkey／FakeGateway，新增真實LightGBM訓練、模型選取、放行與拒絕、設定固定及20分鐘退出。SDK呼叫數為0，沒有直接交易API mutation，沒有page error。
- 既有行情快照可完成重訓與原生模型載入；少量事件可能完全沒有有效樹分裂，因此報告與選單明示固定分數，不把有模型檔視為已學到可用規則。沒有新增市場資料或盤中真實成交驗證。
- 真人開發版沿用預設PasskeyStore與獨立埠；登入畫面及既有Passkey驗證選項可用。實體Touch ID／安全金鑰解鎖仍由使用者完成，與虛擬驗證分開。
