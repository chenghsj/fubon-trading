# Paper 費稅、保存與策略

日期：2026-11-15。Paper 使用正式行情及既有 Keychain 憑證，`FUBON_MODE=paper`、`FUBON_ENABLE_LIVE_TRADING=false`。所有委託都由本機 PaperBook 撮合，不能呼叫券商下單 API；正式行情登入及權限仍須成功。

## 使用方式

1. 手動委託選 `LOCAL / PAPER-F`；自動策略固定使用獨立 `LOCAL / PAPER-AUTO-F`。策略帳戶不能用手動新增或改刪單，避免部位混用。
2. 臺指、小台、微台手動下單沿用既有瀏覽器商品費率；未保存時顯示成本假設。每張單保存其費率及來源，之後調整設定不改寫舊單。策略單使用同日計畫凍結成本。
3. 「自動交易」面板同時顯示 paper 帳簿、委託、持倉、已付費稅及扣成本淨額；行情無法取得時仍可查看已保存資料，浮動損益另需行情。
4. 策略支援既有 ORB／權值股濾網及 ATR V2，仍由使用者啟動。服務重啟只載紀錄，必須手動重新對帳或恢復；不追補舊訊號。
5. 隔日保留的策略部位可用「確認退出保存的 paper 策略部位」，解除風控鎖後以原具體合約新鮮日盤行情嘗試 IOC 退出，不恢復新倉。原合約過期或沒有有效報價時保留資料並阻擋，不改用近月價格。帳簿未平倉或有活動委託時不能封存，新交易日也不能吸收舊倉。

## 計算與資料

- 手續費：本次成交口數 × 委託凍結的每口單邊費率，金額保留到分。
- 指數期貨稅：每口成交價 × 契約乘數 × 0.00002，逐口四捨五入至元，再乘口數。預設適用 TXF／MXF／TMF，其他商品未設定的成本明示為未設定。[期交所費率表](https://www.taifex.com.tw/cht/4/feeSchedules)、[微台契約](https://www.taifex.com.tw/cht/2/tMF)。
- 實現毛利由成交價、方向、平倉數量及乘數計算；帳簿淨額扣除所有已付費稅，包含未平倉單已支付的進場成本。部位面板顯示未實現毛利，帳務另扣已付成本，避免重複扣費。策略視圖使用同一成交價格及計畫成本獨立投影，不再從已扣成本的帳戶淨額扣一次。
- 每筆保存實際成交曆日 `filledDay`。每日帳務按台北曆日歸屬，夜盤跨午夜分日，未實作交易所夜盤交易日曆；累計現金與權益另外計算。`strategyDay` 保留原策略日，使跨日恢復成交仍可對齊原計畫。
- `paper_books` 在同一 SQLite `BEGIN IMMEDIATE` 保存委託、唯一成交、部位及成本；`paper_tags` 唯一限制策略識別碼。跨程序先載最新帳簿再改寫，提交完成才發事件；未改變帳簿的行情不重寫內容。
- `research_auto_runs` 依 `mode + day + account` 隔離，舊紀錄遷移為 sandbox；研究／自動交易仍共用 writer lease。遷移延後到實際讀寫紀錄時，demo 初始化不觸及研究資料庫。
- 只恢復仍在當次時段的 ROD 訂閱；過期委託取消，不能跨日突然成交。保存只涵蓋新版寫入的資料，舊版記憶體狀態無法回溯。

## 驗證與限制

`test_paper.py` 用臨時資料庫核對雙邊費稅、逐口取整、多空／反轉、減量／取消、凍結成本、跨程序及重複 tag、提交失敗回滾、每日／累計、模式遷移與 paper 策略進出場／跨日恢復。全 Python 測試強制隔離預設研究路徑。`verify-paper-trading.mjs` 另以合成行情、真 PaperBook 與虛擬 authenticator 驗證 UI 及真正後端重啟，不讀 Keychain、不呼叫 SDK。

撮合未模擬排隊、部分成交、市場衝擊、保證金占用或每日結算；保存與策略流程通過不代表獲利能力。LightGBM 研究版不會自動替換執行策略。
