## 籌碼與盤別

原本「籌碼資訊」在富邦服務下改接「法人與股權分布」。股票使用選取代碼，個股期以官方 Products 的 `contractType=S` 與 `underlyingSymbol` 帶入股票；指數期貨提示另選股票。切換商品後清除前一商品結果。ETF 分頁獨立輸入 ETF，預設 0050，不將一般股票當 ETF 查詢。其他券商保留舊籌碼卡。

「交易模式設定」新增期權行情與委託盤別。`regular`／`afterhours` 由同一份設定控制報價、K 線、逐筆、五檔、商品清單及期權委託，避免行情與送單盤別不一致；股票不帶期權 session。套用重啟前沿用原模式切換的策略、研究與曝險檢查。切換盤別不改變 Paper／Sandbox／Live 的送單權限；Live 仍需明確確認。舊設定檔或舊客戶端省略 session 時沿用目前設定，不默默切回日盤。

夜盤來源需商品本身提供夜盤。圖表的本機時段篩選不會憑空補上另一盤別來源。期權歷史面板可獨立選擇查詢盤別；研究與自動策略仍維持其原有日盤支援範圍。

CLI 以每個 checkout 的 `server/.watchlists.json` 保存清單、名稱與商品，切換盤別重啟後保留。寫入採暫存檔與原子替換，成功後才更換記憶體；刪除全部清單不會復活預設值。檔案不納入 Git，壞檔不會被預設清單覆蓋；測試預設使用記憶體或臨時檔，不存取真人清單。

## 送出與資料保護

- 券商查詢帳戶從已登入的原生 S／F 帳戶選擇，不把 `LOCAL-PAPER-*` 帳戶送至原生帳務方法。
- Paper／Demo 的原生寫入在後端 DTO 建構與 SDK 呼叫之前拒絕。沒有以實際券商送單驗證任何功能。
- 每筆原生寫入先保存 request ID；本機 Web Locks 與後端 SQLite 防止重複及不確定結果後另開新請求。斷線或逾時不自動重送；未確認狀態跨重新整理與服務重啟保留，須使用者自行核對券商。
- 帳號及金額遮蔽涵蓋子條件、原始內容及錯誤；公開市場數字不受帳務遮金額影響。
- 查詢採白名單，限制日期、數量、商品與欄位，來源逾時、空陣列、無權限及失敗保持可辨識；不把失敗結果快取為正常。

## 驗證與邊界

隔離 QA 使用真 CLI、FastAPI、Broker、NativePanels、React 與瀏覽器，唯讀 vendor 與 WebSocket 為明確合成 fixture，Passkey／帳簿使用臨時資料。[驗收報告](native-panel-connection-qa-2026-11-17.md) 列出每個頁籤、錯誤恢復、指數 SSE、隱私與停用操作。

本地完整前端測試 6,002 passed／2 skipped，後端 800 passed；`tsc -b` 與 production build 通過。獨立 QA 另涵蓋日夜盤設定 42 個後端案例、6 個前端案例、31 個原生送出安全案例及 23 個清單持久化案例，均已包含在完整測試。隔離瀏覽器 71／71 項通過。AI review 找到的期貨 TPSL 子單倉別、選擇權複式市場、追蹤 DTO、未知請求重送、巢狀隱私與個股期標的 metadata 問題均已修正。

這些結果證明接線與資料處理，不證明每個真人帳戶都具有所有行情／帳務權限。正式或 Sandbox 原生送單、成交、條件單生效皆未實測，不能將 SDK 接受請求視為已成交或已有保護。真人服務更新、Passkey 與唯讀結果須另行核對。

後續真人 Passkey 與夜盤代表查詢已完成，詳見 [真人服務唯讀驗證](native-live-readonly-verification-2026-11-17.md)。實測另發現 SDK 原生列舉序列化及錯誤訊息／逾時邊界，已補修正與實際 SDK 常數回歸；最新完整前端 6,014 passed／2 skipped、後端 969 passed，型別與 build 通過。期權委託歷程修正版的真人結果仍須部署後另驗；不能把隔離回歸視為已取得真人紀錄。
