## 實測發現與修正

1. `apiPost` 原本讓原生查詢只顯示 HTTP 400，無法辨別券商的「查無資料」。查詢改用既有 detail 解析，保留狀態碼與完整可遮蔽訊息。另以獨立測試發現錯誤 body 停滯會超過 25 秒，已讓整個查詢與 body 解析共用原有 25 秒期限，不自動重試，不改動券商送出／未知結果鎖。
2. 真 `fubon_neo` 2.5.0 的常數型別屬於 `builtins`，沒有 Python `Enum`／`.name`，並把成員放在同型別 class attributes。原來的反射遍歷因此循環。現以原生 constant namespace 的精確型別與成員對照轉換，不以類別名稱或字串猜測。有限 `Decimal` 轉字串保留精度；非有限值、私密欄位與過深／循環資料仍拒絕或遮除。

新增離線回歸包含 25 類／133 個實際 SDK 常數、巢狀委託、Decimal、敏感欄位、stock／futures history 的 NativePanels 與 HTTP 路徑；不建立 SDK、不讀 Keychain、不連券商。這些測試證明轉換修正，不取代後端更新後的真人再驗。

目前觀察為每類面板的代表查詢，沒有宣稱已逐一核對全部 31 種查詢的真人權限。送單、成交、條件單生效與正式交易均未實測。
