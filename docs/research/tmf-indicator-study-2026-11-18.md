# RSI、KD、MACD等指標：固定配對比較

本輪回應使用者提出的MACD、RSI、KD與其他可用指標。目標是檢查指標特徵的增量資訊；沒有預設它們能改善收益。本文件在第一次讀取本輪績效前固定家族與方法。原始資料、V3、已保存失敗模型與Paper停止狀態全部保留。

用途、來源及跨函式庫差異見[官方來源筆記](tmf-indicator-sources-2026-11-18.md)。本輪僅離線研究，不建立券商連線、不保存成可選執行模型、不啟動交易。

## 固定指標定義

全部只用當刻已收盤棒、按實際session開盤對齊，夜盤跨午夜不重設；每盤重新初始化，不借前盤資料。原V3在135分鐘暖身後才有事件，所以下列1m／3m特徵均已暖身。

- **MACD(12,26,9)，1m／3m**：第26棒對齊種子，慢EMA為首26均值、快EMA為同26棒內末12均值；之後係數2/27、2/13；第26–34棒的9個DIF均值為signal種子，其後係數2/10。第35棒才有真實前後histogram變化。特徵為方向對齊的DIF、signal、histogram、histogram變化，除以訊號當刻已知的3m ATR。15m標準MACD需34棒、histogram變化35棒，超過一個300分鐘日盤的20根15m；本輪15m保留原ER8，未用不完整MACD假裝完成。
- **RSI14，1m／3m**：前14個close差的平均上升／下降為種子，後續Wilder平滑。全平定義50；level為side×(RSI−50)/50、change為side×ΔRSI/100。這個全平定義不宣稱與TA-Lib逐點相同。
- **KD(9,3,3)，1m／3m**：最近9完整棒的RSV；K=(2×前K+RSV)/3，D=(2×前D+K)/3；初始K=D=50，零高低差RSV=50。首個變化須兩個有效K。輸入K位置、K−D與K變化，方向對齊並正規化。這是明定遞迴版本，沒有混用TA-Lib STOCH的SMA版本。
- **Bollinger20／2σ，3m**：最近20完整3m收盤均值、母體標準差；輸入方向對齊的z-score、4σ寬度／ATR、寬度變化／ATR，零標準差z=0。不用未確認pivot。
- **ADX／DMI14，3m**：以前14次TR、+DM、−DM轉移sum為種子，之後Wilder sum遞推；首14個DX均值為ADX種子，之後Wilder平均。輸入ADX強度、方向對齊的DI差、ADX變化，各除100。明定本研究seed，未宣稱與函式庫數值完全相同。
- **當盤近似VWAP**：從開盤累計minute HLC3×volume／累計volume；輸入方向對齊的收盤偏離／ATR與過去3分鐘VWAP變化／ATR。這是分鐘資料近似，沒有逐筆精確成交均價；若量不足無法計算則整個配對研究拒絕，不刪掉其中一組不利樣本。

## 選擇與封存評估

1. 日／夜盤分開，完整開盤日60/20/20切分。只建立前60%事件，在全期30–40%、40–50%、50–60%三塊前推；每塊只fit其之前已結束標籤。最早30%提供初始學習資料，後40%不進開發。
2. 每組LightGBM淨收益迴歸固定100輪、7葉、深度3、葉至少30事件、L2=10、learning_rate=.03、seed42，與第二輪參照相同。標籤為既定政策的成本後淨額；特徵不含下一根開盤或未來收益。
3. 每組門檻只比NT$0／50／100；九組共27組合，每盤全部保存。各組獨立依開發區塊選擇門檻，要求每塊至少20一般成交、一般／加重滑價／延後均正額，壓力場景兩分支各至少15成交且正淨額。排序先eligible、再最差塊壓力淨額、再總壓力淨額減半最大一般分鐘收盤回撤；無eligible則只留診斷。
4. 前60%fit各組最終原生模型，凍結九組門檻、精確日期、全部原始碼與套件、模型SHA256；另一個evaluation階段預定評估全部九組，而非看後段才選擇要報哪組。後段只能作配對描述，不據此自動部署最佳家族。
5. 各組保存一般、每邊額外2點滑價、延後1分鐘的不同交易數、淨額、分鐘收盤估計回撤、分支及去最佳日結果。延後仍受原signal期限與last-entry；它是假設成交延遲價格敏感度，現有V3跨分鐘會取消訊號。
6. 後段歷史已參與先前研究，仍明示重用資料；本輪增加的27組也計入累計嘗試。原正式樣本、獲利與新日期驗證目標不降低，`adoptionAllowed`／`executionEnabled`永遠false。數值片段為正不能直接稱為有優勢或核准自動交易。

```sh
uv run --directory server --extra learning python ../scripts/research-indicators.py --stage development
uv run --directory server --extra learning python ../scripts/research-indicators.py --stage evaluation
```

結果與原生模型保存於`.fubon-dev/reports/indicator-paired-v1/`，不覆寫舊紀錄。實際結果與工程驗證在完成後追加。
