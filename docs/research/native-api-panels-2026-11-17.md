# 富邦原生 API 功能版面與轉接（2026-11-17）

本次新增九類功能面板，入口為「新增面板 → 富邦 API · 版面已備妥」。這些是依用途分組的功能畫面，不是 API 健康狀態總覽。查詢參數、分頁、條件草稿增刪與行事曆月份切換可操作；遠端查詢、訂閱及送出全部停用。畫面不使用合成數字冒充真實資料。草稿未儲存至券商。

| 面板 | 使用情境 |
| --- | --- |
| 資券與當沖配額 | 分別查看融資／融券額度與成數，以及個股現沖配額、預收券與處置狀態 |
| 券商交割與損益 | 交割款原始明細、證券已實現、期權平倉紀錄、信用維持率；與 Paper 帳簿分開 |
| 富邦智慧條件單 | 編輯多條件、觸發後委託、停損停利、移動鎖利與期貨條件單草稿 |
| 法人與股權分布 | 三大法人股數、董監持股與設質、ETF 成分權重、集保級距 |

每個分頁附對應官方文件。依官方 [AI 輔助開發](https://www.fbs.com.tw/TradeAPI/docs/welcome/build-with-llm/)提供的 llms.txt／llms-full.txt 核對資料與欄位。官方文件中沒有保證的 OR 邏輯、MACD 柱狀值、指數清單參考值等沒有列為原生能力；交割資料日期不冒充銀行扣款日，期權平倉紀錄不推造配對開倉價或損益。

## 本輪完成的 adapter

- 排行榜：上市與上櫃 Movers／Actives／Quotes 合併排序；不同交易日或任一市場失敗不發布部分結果。未知欄位保留 null。
- 分價量：原生 session-to-date volumes，完整價位；期貨缺內外盤時僅顯示總量，股票保留未分類餘量。
- 選擇權清單：Products＋Tickers 的 roots、實際到期日、權別、已確認履約價與乘數；非法篩選與缺必要欄位拒絕。不推測未知個股選擇權價格縮放。
- 最新交易日逐筆：AllDay 分頁、去重、最多 50,000 筆與截斷提示；LastCount 獨立。不同來源日期不冒充指定歷史日。
- Paper 已實現損益：由持久成交帳簿重建平均成本，涵蓋部分平倉、反手與費稅分攤；缺必要乘數或已設定成本的缺費稅明確拒絕。不是券商帳務驗收。
- 個股期近月／次月：富邦依具體月份每 root 選最近兩月，不再依賴不存在的 R1／R2 別名。
