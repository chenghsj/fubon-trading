# 秒級成交研究 v1（2026-11-18）

在查看本輪秒級標籤與模型結果前固定。Paper 停止；沒有 broker、下單或策略設定寫入。父版回升／鎖倉研究未通過獲利資格；本輪不放寬原採用門檻。

## 資料與缺口

使用官方公開最近30交易日下載索引實際列出的已完成日期，排除今天與未來檔；原ZIP、CSV及實作保留SHA256。TMF只取實際YYYYMM單式契約，使用CSV的實體日期／時間；跨月價差排除。開盤集合競價是實際成交，不當試撮排除。重複時間／價格／量不去重；原列號不是交易所流水號。同秒聚合只有VWAP、high、low、raw B+S量和筆數；不猜open／close或同秒先後。

先以同時間、同實際月份與既有Fubon Paper歷史1m快照對帳。檢查high／low、B+S原量及除二量與API volume的相符率，首末秒範圍是否涵蓋API open／close。這只能確認必要條件，不證明同秒順序。缺少bid／ask、深度、次秒時間與序號，禁止逐筆可成交回測、淨利或心理真值標籤。兩側數量比例／VWAP不受固定單位倍數影響；量單位需以對帳結果陳述。

同一盤至少99%的分鐘有同月份成交才列入可用開盤日。對帳high／low、首秒涵蓋open、末秒涵蓋close三項相符率各至少99.5%才進行該盤探索模型；未達先保留差異、不改時間偏移或猜新單位。每個衍生秒檔都與原始ZIP重新解析逐列比對，不只檢查檔名與筆數。

## 預先固定的探索比較

這是價格預測的消融比較，不是策略選擇或已扣成本獲利模型。只用既有完整日盤／夜盤快照中有同月份成交資料的開盤日，各盤分開。每三分鐘收盤、至少90分鐘暖身，保留原300／840分鐘盤長；當盤結束前留足30秒。所有1m／3m／15m型態沿用原63維 `candle_patterns.shape`，另加盤內時間比例。個股共同學習的既有研究保留，本項只新增TMF秒級診斷，不把缺少的股票逐筆資料補造出來。

新增特徵只讀時間戳嚴格小於決策秒的已完成秒：1／3／5／15／30秒VWAP變化、5／15／30秒高低範圍、30秒價格變動路徑長度／上漲比例／轉向比例、5秒對此前25秒的每秒量與筆數比、30秒VWAP高點回吐／低點反彈、觀測秒比例與價格陳舊秒數。基準與各lag的最近成交最多落後指定秒2秒；最近30秒至少10個有成交秒。不使用買賣方標記、假BBO、未來資料或情緒名稱。

標籤是未來30秒窗口的末個已觀測秒VWAP減決策前最後秒VWAP，除以當下1m ATR，截於±3；未來末秒距窗口末端最多2秒。另保存原始點數、未來VWAP路徑最高／最低、相對末值的多／空有利變化回吐。這些是事後價格路徑，不是持倉損益，也不是秒內極值先後。反轉診斷＝此前5秒VWAP變化與未來30秒變化異號。

每盤按可用完整開盤日先60% fit、再20% validation、末20% reused-history；不重排、不依結果挑日。所有fit標籤完成時間必須早於validation第一開盤日零時；夜盤前一開盤日跨入該零時之後的fit觀測須清除，fit指標也只算實際fit集合。兩個輸入版本用完全相同有效觀測、日期及標籤，等日權重。fit最低10日／1000觀測；不足如實停止該盤模型，不下修門檻。這個門檻只服務探索價格預測，不能取代原交易採用資格。

固定LightGBM regression L2、7葉、深度3、leaf40、L2=100、100輪、learning_rate=.03、seed42、單執行緒。比較64維K棒與64+秒級維度；不調參、不從validation晉升。零變化預測為額外負控制。輸出ATR與點數MAE、非零方向命中、逐日配對誤差；末段以開盤日為抽樣單位、seed42、2000次bootstrap給出秒級減K棒MAE差的95%區間，不把同日觀測當獨立樣本。原歷史價格已被多輪研究用過，並非全新樣本外；日數短、盤勢覆蓋有限。沒有歷史報價時 executionAllowed／adoptionAllowed 永遠false。

## 群體行為的解釋邊界

價格與量只能推估可觀測群體行為，不能識別個人心態或主力身分。高量低位移可以是吸收、雙邊換手或其他原因；缺委託／撤單事件時不計算完整OFI。研究依據 [Cont等原論文](https://arxiv.org/abs/1011.6402) 是50檔美股的最佳買賣價供需失衡，不能直接外推成TMF有獲利能力。
