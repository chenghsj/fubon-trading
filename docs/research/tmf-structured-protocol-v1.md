# TMF 虧損歸因後結構訊號研究：執行前規格

2026-11-18。本輪始終維持Paper停止，不接入執行引擎。
先以舊凍結模型與保存成交拆解虧損，沒有重訓或從後段選取可部署政策。
固定路徑還原成本只供會計歸因，不等同無成本重跑。已重用的日期都屬探索資料。

## 根據與假設

1. 日盤短方案歷史測試50筆固定路徑毛利3060元，費2000、稅892、滑價2000，淨虧1832；要求訊號到目標有至少三倍估計成本空間。
2. 長方案日盤測試27筆、19筆停損，固定路徑毛虧4550；夜盤23筆、18筆停損，固定路徑毛虧5200。改用有15分方向、先回撤再1分恢復的訊號及3分鐘ATR停損尺度。
3. 日盤flexible的訓練正分數871動作／24日平均實現+407.25，校準正分數15動作／4日平均−96.27；相關係數由0.280降至0.041。夜盤亦有預測關聯下降。這符合泛化不足，但不證明單一特徵是原因。減少重疊、移除星期／月份特徵，增加正則化和簡單線性對照。
4. 延遲回放往往換了選到的交易序列，不能把總損益差都叫同筆交易滑價；新標籤比較同一訊號正常、壓力、延遲的最差結果，再做完整序列檢查。

## 兩類因果訊號

從當盤66分鐘起，1分收盤判斷，3／15分鐘只用完整棒；建構3分布林、回撤參考及停損用ATR時排除訊號分鐘結束的3分棒。當刻已收盤棒可作一般模型特徵及15分方向判斷。
沿用原MACD／RSI／KD／VWAP特徵，移除星期與月份正餘弦；新增恢復幅度、前棒回撤、扣成本目標風險比。
價格需先有一分鐘反向／持平，再向交易方向恢復，恢復幅度不超過0.75倍3分ATR。

- 區間：四個完整15分收盤ER≤0.35，價格在先前20個3分收盤均值至少一個標準差之外；往均值恢復。停損max(30,ceil(0.75×3分ATR14))，目標固定訊號時均值並向較保守整點取整，至少1.3R及三倍成本，期限30分鐘。
- 順勢：同一ER≥0.55，方向一致；價格離先前8個3分收盤均值不超過1倍3分ATR，回撤後恢復。停損max(30,ceil(3分ATR14))，目標2R且至少三倍成本，期限60分鐘。

區間目標在模擬入場報價再核對1.3R／三倍成本，保持原目標不移動。停損距離隨確認成交價固定。每邊費20元、滑價2點、稅率0.00002、點值10元；成本來源仍是假設。壓力每邊再加2點，延遲晚一分鐘但保留原訊號／期限／最後進場限制。單口、每盤兩次、每方向一次、估計預算1000元、偏離10點等限制維持。

這些門檻在看本輪收益前固定，不以後段微調。訊號與停損等同時改動，不能把改善獨立歸功於其中一項。

## 模型與資格

訓練每方向／方案／5分鐘桶取最早訊號，選樣不讀未來盈虧；等開盤日總權重。
標籤為成本後淨利除以訊號時估計風險；預測轉回當下估計元金額，分數不是勝率。

四個固定對照，依序比較標籤、模型及訓練窗：

1. ridge-normal：全部前期日期、普通執行標籤，標準化及截斷±5，Ridge λ=100（截距不懲罰）。
2. ridge-robust：改用同訊號正常／壓力／延遲最低淨利，無法成交該情境以0記，不從訓練中只挑三種都能進場者。
3. tree-robust：改用7葉、深度3、最少40樣本、L2=100的LightGBM，150輪、學習率0.03、seed42、2緒、確定性計算。
4. tree-recent：同上，訓練加校準限前期最近120個完整開盤日。

每模型比較0／30元門檻與區間／順勢／混合，另有三個純規則基準，共27政策／盤，兩盤54項。沒有臨時增加候選或按後段改參數。

總日期前60%開發、中20%驗證、後20%重用歷史測試；發展折30–40%、40–50%、50–60%。每個前綴再80%fit／20%校準，標籤終點早於校準段開始；訓練特徵標準化僅在fit段，校準後不重新fit。

改用實際政策回放的校準閘門，而非把所有反事實動作混成分數箱：校準各情境至少20筆，淨利與扣最佳日淨利皆正，每啟用方案各情境至少5筆且正。未通過便等待，並保留未套閘門的原始診斷。
各發展折各情境至少30筆、正淨利、扣最佳日仍正，啟用分支壓力合計至少20筆正收益才能選擇；否則selected=null。
最終驗證各情境至少30筆、歷史測試各情境至少100筆、各啟用分支測試至少30筆，兩期各情境淨利、扣最佳日及各啟用分支皆正。
保存全部原始及套閘門結果；後段原始正收益不能翻案。凍結資料、精確日期、程式、文件、套件、模型與最終校準閘門後才跑後40%。

本規格沿用時間順序原則，見[scikit-learn官方文件](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)；Ridge為自實作的加權L2閉式解，LightGBM的L2參數見[官方參數](https://lightgbm.readthedocs.io/en/stable/Parameters.html)。通過數字門檻仍不能保證未來穩定獲利，所有模型只供離線研究。
